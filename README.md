## 💼 Flagship Project

### 🔸 **Webbo3** – AI-Powered EdTech Platform  
A gamified learning platform for African tech learners, featuring an AI instructor (Kemi), cohort-based courses, and a live virtual classroom experience.  
- Courses: JavaScript Mastery, Data Analysis Launchpad, Frontend Development, Brand with AI, AI Automation
- Stack: **Flask**, **PostgreSQL**, **SQLAlchemy**, deployed on **Railway**
- Frontend: **React** / **Next.js** / **Tailwind CSS**
- Payments: **Flutterwave**, **Paystack**, **Bitnob** (NGN rails)
- Features: gamified HUD (boss HP bars, streaks, rank badges), SP (skill point) reward system, pod-based cohorts, persistent session state
